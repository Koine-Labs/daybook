# Daybook

Daybook is a cross-platform daily journaling system built as a Turborepo + pnpm monorepo. It spans an iOS/watchOS client (`apps/ios`), a web client (`apps/web`), a Python inference stack (`apps/inference`), a Python server (`apps/server`), embedded firmware (`firmware/`), and shared TypeScript packages (`packages/shared`, `packages/persona`, `packages/ui`). See [`docs/POSITIONING.md`](docs/POSITIONING.md) for the product positioning and the broader vision.
